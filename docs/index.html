Политика конфиденциальности

Дата вступления в силу: 25 августа 2026 г.

1. Общие сведения

Приложение Бюджет+ (далее — «Приложение») разработано KuzyaCrudit и предоставляет пользователям инструменты для ведения личного или семейного бюджета.

2. Сбор данных

Приложение не собирает и не передаёт какие-либо данные третьим сторонам. Все введённые пользователем данные (транзакции, категории, лимиты, сценарии, сведения о льготах) хранятся исключительно на устройстве пользователя в локальной базе данных SQLite.

Приложение не требует доступа к интернету для своей основной работы. Обновление справочника льгот и субсидий выполняется пользователем вручную и не осуществляется автоматически.

3. Идентификаторы устройства

Приложение может использовать стандартный идентификатор устройства (anonymous application installation ID) для технических целей (уникальная идентификация экземпляра приложения). Данный идентификатор не является персональными данными и не используется для отслеживания пользователей.

4. Разрешения

Приложение не запрашивает доступ к геолокации, контактам, камере, микрофону или иным персональным данным.

5. Конфиденциальность детей

Приложение не предназначено для лиц младше 13 лет и не собирает информацию от детей.

6. Безопасность данных

Все данные хранятся в зашифрованной (при наличии поддержки ОС) локальной базе данных. Приложение не осуществляет передачу данных по сети.

7. Изменения в политике

В случае изменений в политике конфиденциальности обновлённая версия будет опубликована на этой странице с указанием даты вступления в силу.
